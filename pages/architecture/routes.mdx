# Routes Reference

Complete reference of all 72 pages in the application.

## Auth Routes `app/(auth)/`

Unauthenticated pages for account management.

### `/signin`
- Email/password login
- Lucia session creation
- Rate-limited (10 attempts per 15 min)
- Redirects to /dashboard on success

### `/signup`
- New user registration
- Email validation
- Password requirements: min 12 characters
- Auto-login on success → /onboarding/welcome

### `/reset-password`
- Password recovery flow
- Email-based reset link
- Token expiration: 1 hour

## Onboarding Routes `app/(onboarding)/onboarding/`

9-step guided onboarding flow for new users.

### `/welcome`
- Introduction to platform
- Overview of onboarding process
- Navigation to symptoms step

### `/symptoms`
- Primary symptom selection
- Secondary symptoms (optional)
- Severity rating: mild | moderate | severe
- Duration selection
- Saves to profile.questionnaire.primarySymptoms

### `/goals`
- Wellness goal selection
- Learning style preferences
- Time commitment (5-10-15-30 min/day)
- Support network preference (alone, group, provider)

### `/assessment`
- Full GAD-7 (anxiety assessment)
- Full PHQ-9 (depression screening)
- Crisis screening (suicidal ideation check)
- Auto-scores and stores in profile.assessment
- PHQ-9 Item 9: If score >= 2, show crisis modal

### `/your-experience`
- Therapy history (yes/no, current therapist)
- Current coping strategies
- Unhelpful coping to change
- Known triggers
- Worst time of day

### `/about-you`
- Age range
- Life stage (student, working, retired, etc.)
- Living situation
- Support network availability

### `/in-your-words`
- Free-text self-description prompts:
  - "What does a good day look like for you?"
  - "What's your biggest challenge right now?"
  - "What kind of support are you hoping for?"
  - "Do you notice any patterns?"

### `/safety`
- Crisis resource acknowledgment
- 988 Suicide & Crisis Lifeline information
- Emergency contact information
- Confirmation before proceeding

### Completion Logic
On completing final step:
1. Compute wellness dimension scores (anxiety, mood, sleep, stress, nutrition)
2. Run recommendation engine (map symptoms to courses)
3. Set currentCourse to first recommended course
4. Mark onboardingCompleted = true
5. Redirect to /dashboard

## Route Protection

### Middleware Protection
- All routes under `(default)`, `(provider)`, `(admin)` require auth
- Unauthenticated users redirected to `/signin`
- Onboarding incomplete users redirected to `/onboarding/welcome`

### Role-Based Access
- Provider routes: require `role = 'provider'` OR `role = 'admin'`
- Admin routes: require `role = 'admin'`
- Patient routes: any authenticated user

### Session Validation
- Lucia validates session on every request
- Expired sessions cleared, user redirected to signin
- 24-hour sliding window (extends on activity)
